# Sistem Reservasi Hotel - SQL Scripts

Dokumentasi mengenai urutan eksekusi script SQL untuk basis data **`sistem_reservasi_hotel`**.

## 📌 Urutan Eksekusi Script

Eksekusi script SQL wajib dilakukan secara berurutan mulai dari nomor `01` hingga `09`:

1. **`01_ddl_tables.sql`** : Membuat Database & Tabel-tabel utama (DDL).
2. **`02_seeding_data.sql`** : Mengisi dummy data awal.
3. **`03_generate_large_data.sql`** : Mengisi 5.000 data kamar acak via Stored Procedure.
4. **`04_function.sql`** : Membuat Stored Functions.
5. **`05_procedure.sql`** : Membuat Stored Procedures dengan Cursor & Condition handling.
6. **`06_trigger.sql`** : Membuat Triggers otomatisasi database.
7. **`07_index.sql`** : Membuat Composite Index & Unique Constraint.
8. **`08_view.sql`** : Membuat Views (Horizontal, Vertical, Nested Check Option).
9. **`09_database_security.sql`** : Membuat User, Role, dan Hak Akses (Privileges).
